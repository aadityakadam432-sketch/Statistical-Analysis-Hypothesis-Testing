# Statistical Analysis and Hypothesis Testing in Python

## Project Overview

This project focuses on statistical analysis and hypothesis testing using Python to examine the relationship between advertising expenditure and product sales.

## Dataset

The dataset contains:

* TV advertising expenditure
* Radio advertising expenditure
* Newspaper advertising expenditure
* Product Sales

## Statistical Methods

* Descriptive Statistics
* Pearson Correlation
* One-Sample t-Test
* 95% Confidence Interval
* Multiple Linear Regression
* ANOVA
* Chi-Square Test

## Tools & Libraries

* Python
* Pandas
* NumPy
* SciPy
* Statsmodels
* Matplotlib
* Seaborn
* Google Colab

## Visualizations

The project includes histograms, scatter plots, correlation heatmaps, regression visualizations, box plots, and residual analysis.

## Objective

The objective is to determine whether advertising expenditure has a statistically significant relationship with product sales using hypothesis testing and statistical analysis.

## Files

* `Statistical_Analysis_Hypothesis_Testing.ipynb` – Google Colab/Python notebook
* `Advertising.csv` – Dataset
* `statistical_analysis_results.csv` – Analysis results
* `Statistical_Analysis_Report.docx` – Detailed project report
